# Polaris — бронирование лаундж-зон

Полноценное Rails-приложение для управления лаундж-зонами частного здания:
каталог зон, бронирование с модерацией, личный кабинет члена клуба и админка
с аналитикой. Интерфейс — на русском языке.

## Стек

| Слой | Технология |
| --- | --- |
| Фреймворк | Ruby on Rails 8.1, Ruby 3.2 |
| БД | PostgreSQL 14 (exclusion constraint против двойных броней) |
| Фронтенд | Hotwire (Turbo + Stimulus), Importmap, Tailwind CSS 4 |
| Аутентификация | встроенный генератор Rails 8 (has_secure_password) + роли |
| Авторизация | Pundit (роли: член клуба / менеджер / администратор) |
| Фоновые задачи | Solid Queue (БД-backed), письмо-напоминания по расписанию |
| Аналитика | Chartkick + groupdate |
| Тесты | RSpec + FactoryBot + shoulda-matchers |
| Качество | RuboCop (rails-omakase), Brakeman, bundler-audit |

## Возможности

- **Каталог зон** — публичная витрина: вместимость, этаж, удобства, цена за час,
  минимальная/максимальная длительность.
- **Бронирование** — форма на странице зоны; бронь на зону с модерацией
  попадает в статус «На рассмотрении», для зон без модерации подтверждается
  автоматически. Цена фиксируется на момент создания брони.
- **Защита от двойного бронирования** — и на уровне приложения, и на уровне БД:
  exclusion-констрейнт `reservations_no_overlaps` (btree_gist + tsrange) не
  даст двум активным броням одной зоны пересечься даже при гонке запросов.
- **Личный кабинет** — предстоящие и прошедшие брони, отмена.
- **Админка** (`/admin`, доступна менеджерам и админам):
  - дашборд: брони по дням, выручка по неделям, пиковые часы, дни недели,
    статусы, популярные зоны и загрузка зон в %;
  - модерация броней: подтвердить / отклонить / отменить / завершить;
  - CRUD зон и удобств;
  - управление ролями пользователей (только админ).
- **Уведомления** — письма при создании/подтверждении/отклонении брони и
  напоминание за сутки (recurring-задача Solid Queue).
- **Регистрация** — открытая для членов клуба (роль member).

## Запуск

Требуются: Ruby 3.2+, PostgreSQL, Redis не нужен.

```bash
bin/setup            # гемы, БД, сиды
bin/dev              # сервер + Tailwind + Solid Queue
```

Открыть http://localhost:3000

Демо-доступ после сидов:

| Роль | Логин | Пароль |
| --- | --- | --- |
| Администратор | admin@polaris.test | password123 |
| Менеджер | manager@polaris.test | password123 |
| Член клуба | anna@polaris.test | password123 |

В dev-окружении письма открываются в браузере (letter_opener).

## Тесты и проверки

```bash
bundle exec rspec          # 37 спек: модели, сценарии, авторизация
bundle exec rubocop        # стиль
bundle exec brakeman       # безопасность
```

## Структура

- `app/models/reservation.rb` — домен брони: валидации, расчёт цены,
  конечный автомат статусов (`TRANSITIONS`).
- `app/models/analytics/dashboard.rb` — запросы для дашборда.
- `app/policies/` — Pundit-политики.
- `db/migrate/…_create_reservations.rb` — exclusion constraint
  `reservations_no_overlaps`.
- `config/recurring.yml` — ежедневные напоминания (10:00, production).

## Идеи для развития

- загрузка фото зон (ActiveStorage уже подключён);
- повторяющиеся брони и чёрные даты (закрытие зон);
- онлайн-оплата и предоплата;
- экспорт отчётов в CSV/XLSX;
- уведомления в Telegram.
